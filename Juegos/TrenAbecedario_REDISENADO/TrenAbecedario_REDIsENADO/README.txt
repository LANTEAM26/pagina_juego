EL TREN DEL ABECEDARIO - EDICIÓN REDISEÑADA

1. Abre index.html directamente con doble clic. No requiere localhost ni conexión.
2. Selecciona cualquiera de las seis estaciones; ninguna está bloqueada.
3. Arrastra las letras a los vagones o toca una letra para colocarla automáticamente. También puedes seleccionar un vagón y después una letra.
4. Usa Deshacer para retirar la última colocación y Borrar para vaciar la ronda.
5. El tiempo y el mejor tiempo de cada estación se guardan en el navegador.

ARCHIVOS:
index.html - entrada
css/styles.css - paisaje, menús y mapa
css/panels.css - juego, tren grande y paneles
css/animations.css - animaciones
js/game.js - juego principal independiente para que funcione desde file://
js/levels.js, train.js, main.js, audio.js, storage.js - espacio reservado para futuras ampliaciones modulares (no se cargan en esta edición para permitir apertura directa).
assets/ - carpetas listas para imágenes y audio.

NOTA: los gráficos del tren y paisajes usan CSS y emojis. No hay archivos de música externa incluidos.

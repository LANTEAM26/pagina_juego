GATO PESCADOR
==============
Abre index.html en un navegador moderno.

Estructura:
- index.html
- css/styles.css
- css/animations.css
- js/game.js
- js/audio.js
- assets/images/gato
- assets/images/peces
- assets/images/fondos
- assets/sounds
- assets/music

Actualmente usa personajes/objetos dibujados con CSS y emojis para que funcione sin recursos externos.
Puedes reemplazarlos después por sprites PNG manteniendo la lógica de game.js.
